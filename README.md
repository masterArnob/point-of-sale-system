# POS System

Welcome to the Point of Sale (POS) System! This project is designed to manage the sale transactions, including handling products, coupons, suppliers, orders, invoices, and providing earnings insights.

## Features

- **CRUD Operations for Products**: Create, Read, Update, and Delete products in the inventory.
- **CRUD Operations for Coupons**: Manage discount coupons with full CRUD functionality.
- **CRUD Operations for Suppliers**: Handle suppliers with CRUD operations.
- **Order Management**: Manage and process orders efficiently.
- **Invoice Generation**: Generate invoices for completed orders.
- **Dashboard Insights**: View earnings for today, this month, this year, and total earnings.
